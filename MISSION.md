# Mission: Java backend fundamentals

## Why
Land a Java backend job. The user is an experienced programmer in another language and must be able to maintain and extend an existing Spring Boot backend: write controllers, services, repositories and tests in the style of the Ledgerly repo.

## Success looks like
- Open any file in this repo and follow what each line does (syntax, types, control flow, classes, records, lambdas)
- Trace a request through controller, use case, domain and repository, and say where each kind of change belongs
- Add a field or an endpoint end to end (contract, controller, service, entity, migration, tests) and keep `make test` green
- Explain Java and Spring Boot choices in an interview

## Constraints
- 10-15 minutes per session: one tiny idea per lesson
- Experienced programmer: skip generic programming concepts, focus on Java and Spring specifics
- Every lesson grounded in a real Ledgerly file

## Out of scope
- Generics in depth, reactive programming, Kubernetes/deployment (until the backend flow is fluent)
- Security internals (JWT, Keycloak) beyond reading the code
