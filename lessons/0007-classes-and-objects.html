Lesson 7: Classes and objects

← All lessons · About 12 minutes. Builds on Lesson 6.

The one idea

A class bundles fields (state), a constructor (how to start) and methods (behaviour). An object is created with new, which calls a constructor (Oracle: Constructors).

A constructor looks like a method but has the class name and no return type. If you write none, the compiler adds a no-argument one. Access modifiers on a constructor decide who may call it; if other classes cannot call it, they cannot create objects directly.

Read real code

All in Expense.java:

private ExpenseStatus status;                 // field (state)

private Expense(ExpenseId id, ..., String merchant, String note) {
    this.id = id;                             // parameter -> field
    ...
    this.status = ExpenseStatus.DRAFT;        // every new expense starts as a draft
}

public static Expense draft(TeamId teamId, ..., Clock clock) {
    ... checks ...
    return new Expense(ExpenseId.random(), ...);
}
  • The constructor is private: no other class can write new Expense(...).
  • The only way in is the static method draft, a factory method: it runs the validation, then calls new. An invalid expense cannot exist. (Money.of is the same idea.)
  • this.id = id: this is the object being built, so this assigns the parameter to the field of the same name.
  • Fields are private; outside code reads them through methods such as version() and id().
The class comment explains why this is a class and not a record: it "has an identity ... and changes over time". Lesson 8 shows the other kind.
