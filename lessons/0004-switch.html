Lesson 4: switch

← All lessons · About 12 minutes. Builds on Lesson 3.

The one idea

switch picks a path from one value. It comes in two styles, and modern backend code mostly uses the second.

Classic: colon and break

switch (month) {
    case 1:  name = "January"; break;
    default: name = "Invalid"; break;
}

Without break, execution falls through into the next case. With month = 8 Oracle's example adds August through December (Oracle: switch). It handles byte short char int, enums and String.

Modern: arrow, returns a value

int n = switch (day) {
    case MONDAY, FRIDAY -> 6;
    case TUESDAY        -> 7;
    default             -> 0;
};

Arrow rules "do not fall through", so no break. Several labels share a rule with commas. A block on the right returns with yield. A switch expression must cover every value; an enum switch covering all constants needs no default (Oracle: switch expressions). Oracle recommends arrows because forgetting break causes accidental fall-through.

Fall-through, traced

Think of the matching case as an entry door, not a filter. Java jumps to the match, then keeps running downward until it hits break or the end.

switch (month) {          // month = 8
    case 8:  add("August");     // entry: runs
    case 9:  add("September");  // no break above: runs
    case 10: add("October");    // runs
    case 11: add("November");   // runs
    case 12: add("December");   // runs
             break;             // stops here
    default: break;
}

Compare case 8 -> ...: the arrow form runs only its own right-hand side. Same input, no fall-through.

Read real code

CsvCells.neutralise, line 28:

return switch (value.charAt(0)) {
    case '=', '+', '-', '@', '\t', '\r' -> "'" + value;
    default -> value;
};

If a cell starts with a spreadsheet-formula character, prefix a quote. Single quotes mean char; double quotes mean String (Lesson 1).

ListExpenses.parseSort:

direction = switch (parts[1]) {
    case "asc"  -> Sort.Direction.ASC;
    case "desc" -> Sort.Direction.DESC;
    default     -> throw new InvalidRequest("sort", "Direction must be asc or desc");
};

A String switch whose default throws. Throwing is allowed on the right of an arrow, so bad input can never produce a value.

Your own enum: ExpenseStatus (DRAFT, SUBMITTED, APPROVED, REJECTED, REIMBURSED). Switching on it with all five cases needs no default.
