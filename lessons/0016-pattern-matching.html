Lesson 16: Pattern matching

← All lessons · About 12 minutes. Builds on Lesson 15.

The one idea

Pattern matching tests a type and extracts the value in one step.

instanceof pattern. shape instanceof Rectangle r tests and declares r, already of type Rectangle, usable only where the test is known true: no separate cast (Oracle: instanceof patterns).

switch patterns. case String s -> ... binds a typed variable; case Integer i when i > 100 -> ... adds a guard. Labels are tested in order; the compiler rejects a label that an earlier one always matches ("dominance"). A switch over a sealed type that covers every subtype needs no default (Oracle: switch patterns).

  • In the first, ready is only usable inside the if, and it is a Ready, so ready.expense() works with no cast.
  • In the second, infected.signature() reads the record's accessor (Lesson 8). Two sealed cases, both handled, no default.
  • In the third, the repo comment says it: "ExpenseException is sealed, so this switch must cover every case." Add a seventh exception to permits and this switch stops compiling until you handle it. The compiler finds the places you forgot.
