Lesson 15: Sealed types

← All lessons · About 10 minutes. Builds on Lesson 14.

The one idea

A sealed type lists exactly who may extend or implement it, using permits. It models a fixed set of possibilities.

public sealed interface Shape permits Circle, Square {}

Each permitted subtype must be exactly one of final, sealed or non-sealed. A record counts as final already (Oracle: Sealed Classes). Because the compiler knows every case, a switch over the type can be checked for completeness (Lesson 16).

Read real code

// MalwareScanner.java line 10
sealed interface Result permits Result.Clean, Result.Infected {
    record Clean() implements Result {}
    record Infected(String signature) implements Result {}
}
