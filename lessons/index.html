Java backend: lessons

Learning Java syntax with the Ledgerly repository as the textbook.

The goal

Land a Java backend job, able to maintain and extend an existing Spring Boot backend. You already program in another language, so these short lessons (10 to 15 minutes each) teach Java's syntax by reading real code in this repo: variables and types, control structures, methods, classes, records, collections, exceptions, interfaces, Optional, sealed types, lambdas, streams and Spring basics, then the Spring Boot request flow from controller to database to tests. The aim is that you can open any file here and follow it line by line, then write small pieces yourself.

Each lesson has one idea, a few quizzes, and a primary source to read. Quick-reference sheets live in variables and types, control flow and classes and records and collections, exceptions, interfaces and modern Java and Spring basics and the Spring Boot request flow and security, specifications and events and operations and configuration. The full mission is in MISSION.md; sources are in RESOURCES.md.
