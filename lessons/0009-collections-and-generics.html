The one idea

Three collection interfaces cover most backend work (Oracle: Collection interfaces):

InterfaceOracle's description
ListAn ordered collection; can contain duplicates; access by integer index.
SetA collection that cannot contain duplicate elements.
MapMaps keys to values; no duplicate keys, each key maps to at most one value.

The type in angle brackets is a generic type argument: List<String> is a list of strings. The compiler then enforces the element type and removes casts (Oracle: Why use generics?).
