Lesson 3: Loops

← All lessons · About 12 minutes. Builds on Lesson 2.

The one idea

Java has three loop shapes. You will meet all of them in backend code.

for (int i = 0; i < 3; i++) { ... }        // counted: init; test; step
for (String item : items) { ... }            // for-each: every element
while (condition) { ... }                    // test first

The for header has three parts: initialization runs once, the termination test is checked before each pass, and the increment runs after each pass. A variable declared in the header lives only inside the loop (Oracle: for). Oracle recommends the for-each form "whenever possible".

do { ... } while (condition); tests at the bottom, so its body always runs at least once; while may never run (Oracle: while and do-while).

Read real code

  1. For-each, ProductionEnvironmentCheck line 45: 
    for (String property : REQUIRED) { ... }
    Read the colon as "in": for each property in REQUIRED. A continue inside skips to the next property.
  2. Counted, CsvCells.row line 37: 
    for (int i = 0; i < cells.length; i++) {
    if (i > 0) line.append(',');
    ...
}
    It needs the index i (no comma before the first cell), so for-each does not fit. Note the brace-less if on one line: legal, but Lesson 2 explained the risk.
  3. While, ClamAvScanner line 73: 
    while ((read = content.read(buffer)) != -1) { ... }
    Inside the condition: read into buffer, store the count in read, then compare with -1 (end of stream). We loop because we do not know in advance how many chunks there are.

Check yourself

How often does for (int i = 0; i < 3; i++) run its body?

Which loop runs its body once even if the condition starts false?

You need every element of REQUIRED and no index. Which header fits?
