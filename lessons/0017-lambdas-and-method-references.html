Lesson 17: Lambdas and method references

← All lessons · About 12 minutes. Builds on Lesson 16.

The one idea

A lambda is a nameless method you can pass around: parameters, an arrow, a body.

p -> p.age() >= 18                 // one parameter, expression body
(a, b) -> a.size() - b.size()      // several parameters
s -> { log(s); return s.trim(); }  // block body needs return

A lambda needs a target type: a functional interface, meaning "any interface that contains only one abstract method" (Oracle: Lambda Expressions). The JDK ships common ones in java.util.function (Predicate, Function, Consumer). A lambda may use local variables only if they are final or effectively final.

A method reference is a shorthand when the lambda only calls one method (Oracle: Method References):

KindExampleSame as
static methodPerson::compareByAge(a, b) -> Person.compareByAge(a, b)
method of a given objectprovider::compareByName(a, b) -> provider.compareByName(a, b)
method of "any object of a type"String::compareToIgnoreCase(a, b) -> a.compareToIgnoreCase(b)
constructorHashSet::new() -> new HashSet()

Read real code

// ScanReceipt.java line 76
Optional<Receipt> found = tx.execute(s -> receipts.findById(receiptId));

// DownloadReceipt.java line 45
.filter(r -> r.isDownloadable())
.orElseThrow(NotFound::new);

// ExpenseDeletedCleanup.java line 38
List<String> keys = found.stream().map(Receipt::storageKey).toList();
  • s -> receipts.findById(receiptId): tx.execute wants a callback; the lambda is that callback and uses receiptId from the enclosing method (effectively final).
  • NotFound::new is a constructor reference: "make a NotFound when needed".
  • Receipt::storageKey equals r -> r.storageKey() (third kind).
