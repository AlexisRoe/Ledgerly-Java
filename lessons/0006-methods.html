Lesson 6: Methods

← All lessons · About 12 minutes. Builds on the recap in Lesson 5.

The one idea

A method declaration reads left to right: modifiers, return type, name, parameters, body.

public long version() { return version; }
public Money plus(Money other) { ... }
public void approve(Actor actor) { ... }

Oracle lists six components (modifiers, return type, name, parameter list, exception list, body). Only return type, name, parentheses and body are required. void means nothing is returned. The signature is the name plus the parameter types: plus(Money) (Oracle: Defining Methods). Method names are lowercase verbs in camelCase.

Read real code

  • Money.plus takes one Money and returns a new Money. It never changes the original.
  • Expense.approve is void: it works by changing status and returns nothing. Methods that answer a question return a value (canDelete returns boolean); methods that act return void.
  • Money.of("12.50", "EUR") is called on the class, not on an object, because it is declared static. Instance methods like plus need an object first: a.plus(b).

Overloading: methods may share a name if their parameter lists differ. Return type does not count, and Oracle advises using overloading sparingly.

Check yourself

In public long version(), what is the return type?

What is the signature of public Money plus(Money other)?

Can one class declare int f(int a) and long f(int b)?
