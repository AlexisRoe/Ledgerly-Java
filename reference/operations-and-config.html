Configuration precedence (low to high)

application.yaml, then application-{profile}.yaml, then environment variables (LEDGERLY_STORAGE_S3_BUCKET), then command line, then test properties. Typed access: @ConfigurationProperties("ledgerly.x") on a record + @EnableConfigurationProperties.

Observability

  • Logs: ECS JSON in prod, text in local; MDC fields userId, teamId
  • Metrics: inject MeterRegistry; scrape :8081/actuator/prometheus; probes /actuator/health/liveness|readiness
  • Traces: Observation.createNotStarted(name, registry), low-cardinality key values only for bounded data

Batch import

Job -> Step (chunk 100, one transaction each) -> reader (CSV) -> processor (RowRejected = skip) -> writer (facade.createDrafts)
identifying parameter: importId; restart = same parameters, resumes after the last committed chunk

CI jobs

verify, openapi-lint, format-config, gitleaks, image. Run make verify before pushing.
