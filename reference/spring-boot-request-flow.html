Spring Boot request flow (Ledgerly)

Sources are linked in the lessons 21 to 28 and in RESOURCES.md.

HTTP request
 -> ExpensesController (internal/web)         implements generated ExpensesApi; parse, call ONE use case, map
 -> CreateExpense.execute (internal/application)   @Service, @Transactional; Command in, Result out
 -> Expense.draft(...) (internal/domain)      rules; throws ExpenseException (unchecked) on refusal
 -> ExpenseRepository.save (internal/infrastructure)  Spring Data interface, derived queries
 <- ResponseEntity; errors by @RestControllerAdvice -> ProblemDetail (application/problem+json)

Annotations cheat sheet

AnnotationMeans
@SpringBootApplicationauto-config + component scan below this package
@RestController, @RequestMapping, @GetMapping...HTTP endpoints (in Ledgerly: generated interface)
@PathVariable / @RequestParam / @RequestBody / @RequestHeaderbind request parts to arguments
@Service / @ComponentSpring-managed bean; constructor injection
@Transactional(readOnly = true)one DB transaction; rollback on RuntimeException/Error
@Entity, @EmbeddedId, @Embedded, @VersionJPA mapping; needs a non-private no-arg constructor
@Validvalidate the Bean Validation constraints of the argument
@RestControllerAdvice + @ExceptionHandlercentral exception to response mapping
@Test, @ParameterizedTest, @SpringBootTestJUnit and Spring tests
