Control flow

Sources: Oracle Java Tutorials, Switch expressions

Conditions

if (a > 0 && b != null) { ... } else if (a == 0) { ... } else { ... }
int x = cond ? 1 : 2;      // ternary

== compares, = assigns. && and || short-circuit. ! negates. Always use braces.

Loops

for (int i = 0; i < n; i++) { ... }   // counted
for (String s : list) { ... }          // for-each
while (cond) { ... }                   // test first
do { ... } while (cond);               // at least once

switch

switch (x) { case 1: ...; break; default: ...; }   // classic, falls through without break

String s = switch (x) {                            // modern expression
    case 1, 2 -> "low";
    case 3    -> { yield "mid"; }
    default   -> throw new IllegalArgumentException();
};

Expressions must be exhaustive. An enum covering all constants needs no default.
