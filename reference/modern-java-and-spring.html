Cleanup

try (var in = open()) { ... }          // AutoCloseable, closed in reverse order
try { ... } finally { cleanup(); }     // runs on any exit (not if the JVM exits)

Optional

Optional<User> u = repo.find(id);
u.isEmpty();  u.map(User::name).orElse("?");  u.orElseThrow(NotFound::new);

Intended as a return type. Prefer orElseThrow() to get().

Sealed and patterns

sealed interface Result permits Clean, Infected {}
record Clean() implements Result {}
record Infected(String sig) implements Result {}

switch (r) {
    case Clean c -> ...
    case Infected i when i.sig().isEmpty() -> ...
    case Infected i -> ...        // guarded case first; no default needed
}
if (x instanceof Infected i) { i.sig(); }

Spring

@Service class Foo { private final Bar bar; Foo(Bar bar) { this.bar = bar; } }

@Component, @Service, @Repository, @Controller / @RestController. Bean name = uncapitalised class name; default scope singleton; the constructor lists the dependencies.
