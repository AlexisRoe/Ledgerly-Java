Specification

static Specification<Expense> hasStatus(ExpenseStatus s) { return (root, query, cb) -> cb.equal(root.get("status"), s); }
Specification<Expense> spec = inTeam(teamId);            // always first
if (status != null) spec = spec.and(hasStatus(status));
repository.findAll(spec, PageRequest.of(page, size, sort));

Events

events.publishEvent(new ExpenseEvent.Created(teamId, id, actorId, clock.instant()));   // inside @Transactional

@ApplicationModuleListener            // = @Async + @Transactional(REQUIRES_NEW) + @TransactionalEventListener
void on(ExpenseEvent.Deleted e) { ... }   // idempotent; throw on real failure so it is re-delivered

Plain @EventListener: synchronous. @TransactionalEventListener: AFTER_COMMIT by default, skipped if no transaction. Events carry ids and field names only.

Adding something: where it goes

  • New endpoint: openapi.yaml, controller method, use case starting with access.actor
  • New filter: Specification factory, nullable field, and in ExpenseFilters.build
  • New reaction: new event record in permits, publish in the use case, @ApplicationModuleListener
